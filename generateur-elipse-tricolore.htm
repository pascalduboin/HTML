Cercle SVG paramétrable

Dimensions extérieures : 385 × 375 mm. Le rouge commence à 0° (en haut, à 12 heures), puis vient le blanc ; le bleu se termine à 360°. Le cercle aplati est entièrement fermé, sans ouverture. Les pourcentages correspondent aux longueurs des segments. La rotation déplace les trois segments ensemble sur l’ellipse, sans modifier sa forme.

Les proportions doivent totaliser 100 %. Le contour est contenu dans les dimensions indiquées. Chaque segment reste indépendant dans le SVG.
